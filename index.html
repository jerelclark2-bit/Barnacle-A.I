How the full Python system works

Model A

Deep learning

A small PyTorch CNN predicts barnacle-center heatmaps, then converts local peaks into candidates. Trained on imperfect contour labels from one photograph.

Model B

Ridge regression

Image tiles are represented with brightness, centroid, symmetry, balance, edge density, and texture features, then regressed onto annotation-derived counts.

Human judgment

Correct & verify

Review problematic tiles and compute sampling-based uncertainty with human counts. Labels remain incomplete; the trained model has not yet been biologically validated.

Reproducibility matters. The model comparison, trained checkpoints and full Streamlit/FastAPI application are in the separately packaged Python project. This browser-only demonstration does not substitute for deploying that backend.
