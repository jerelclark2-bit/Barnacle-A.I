How it works

A small convolutional neural network, trained from scratch in PyTorch, turns the photo into a heatmap of likely barnacle centers. Each peak above the threshold counts as one candidate. Here it runs with TensorFlow.js, so the photo never leaves your computer.

The full Python project also has a Ridge regression baseline built on hand-made image features (brightness, intensity center, symmetry, balance, edges and texture), the evaluation above, and a Streamlit app for reviewing and correcting counts.

There are only two labeled photos to learn from and test on, and those labels miss some barnacles. Treat every count as an estimate until someone checks it by hand.
