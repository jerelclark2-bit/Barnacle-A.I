🔬 How the actual AI worksMethodology and limitations

The full Python project trains a small PyTorch CNN that proposes barnacle center locations, and a Ridge regression model that estimates counts from engineered image features. It is separate from the lighter GitHub Pages browser preview.

Its sample of labeled photos is small, the labels are incomplete, and a reliable automatic 95% prediction interval needs independently validated data. This application never substitutes a polished graph for verified accuracy.
